# 🌍 Mini Translator

![Python](https://img.shields.io)
![MIT License](https://img.shields.io)
![Status](https://img.shields.io)

> A sleek, minimal, and high-speed text translator powered by Google Translate API.

## ✨ Features
*   🚀 **Instant Translation:** Translate any language in milliseconds.
*   🔍 **Auto-Detection:** Automatically detects the source language.
*   🎨 **Clean UI:** Simple terminal interface with emoji support.
*   📦 **Lightweight:** Minimal dependencies, maximum performance.

## 🛠️ Installation
First, ensure you have the `googletrans` library installed:
```bash
pip install googletrans==4.0.0-rc1
python mini_translator.py
